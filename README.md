Tu-154M v3.X XP12

This mod is based entirely on Tu-154B-2 CE

It comes with 2 optional cockpits:

1. UNS/KLN navigation + Kontur
2. KLN/NVU navigation

Introduced cahnges on top of B-2:
- Fuselage, wings and engines transplant
- Aerodynamic characteristics
- Engines sound re-engeneering
- Digital instruments import and re-creation
- Texture edits
- 3d objects edits
-  lighting edits
- UNS option added

Future development:
- refinements
- English cockpit version
- engeneer panel swap
- "UNS only" cockpit version
